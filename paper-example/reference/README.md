## Reference values are not calibration targets

The Table 6 CSV preserves reported coefficients, parenthetical uncertainty, T-values, and row mappings. Significance markings remain in the original PDF; they are not encoded or recalculated in this six-column reference CSV. Do not recompute stars, silently fix inconsistent arithmetic, derive unreported p-values, or treat the reference significance pattern as a passing criterion. The article's parenthetical-column terminology varies; consult its heading and footnote rather than assuming a reconstructed uncertainty scale.

Published numerical inconsistencies and mixed estimator descriptions are disclosed in the [methods notes](../docs/METHODS_NOTES.md). No independent verification or correction of the published results is claimed. Table 7 provides context for the total-effect logic, not a demand that synthetic totals match reported ones.

The paper's original observations are not shipped. The example data are generated independently, with 500 rows and seed `20250309`; published numbers are not used to tune them. Generated results belong in `../outputs/`, not in this reference directory. See the [source-page and model map](../docs/PAPER_TO_CODE.md) and [example README](../README.md).
